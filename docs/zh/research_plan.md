# 研究计划

当前后端目标为用英语进行日语五十音文本教学，按本地 courses/ Skill 脚本引导对话。
教学模型同轮给出回复和表情建议，后端校验后供未来 Unity 呈现；见 [后端开发计划](avatar_integration_plan.md)。
语音与独立情绪模型仅预留接口，Unity 实机呈现和用户研究尚未实施。
现有工程基线见 [Workspace 路线图](internship_agent_workspace_plan.md)。

## 核心问题

与无情绪表达的 Avatar 和真实教师基线相比，由情绪模型驱动的 3D 教学 Avatar 是否能够提升学习者的参与感、自然感、社会临场感和整体学习体验？

## 拟定研究重点

本项目不只是构建一个通用的 LLM Avatar 演示，而是聚焦于具备情绪感知能力的教学 Avatar。系统使用情绪模型，将教学上下文和学生状态转换为面部表情、视线、点头、手势以及语音相关行为。

## 候选情绪模型

- PAD/VAD 模型：适合连续的表情和动作控制。
- OCC 模型：适合教学语境中的认知评价，例如学生犯错后的鼓励，或取得进展后的表扬。
- LLM 辅助估计：适合从对话上下文中抽取结构化的情绪状态。

首版直接校验教学模型的表情/动作建议，不额外调用独立情绪模型。
保留现有 EmotionState 与可替换分析接口；完整情绪模型选择与评估留待后续研究。
呈现 intensity 不代表 PAD/VAD 的第三维，也不表示已测量学生情绪。

## 基线条件

- 纯文本 LLM 教师。
- 无情绪表达的 3D Avatar 教师。
- 基于规则的情绪化 Avatar 教师。
- 情绪模型驱动的 Avatar 教师。
- 真实教师教学作为参考条件。

## 评估指标

- 通过前测和后测衡量学习增益。
- 自我报告的理解程度。
- 参与度和动机。
- 社会临场感。
- 信任感和友好感知。
- 面部表情和动作的自然度。
- 端到端延迟和模块级延迟。

## 作品集目标

该实现也应该作为 AI Agent 方向的作品集项目。系统应展示工具调用、记忆、工作流编排、追踪，以及与实时 3D 客户端的集成能力。
